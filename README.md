# Convertly

**Convertly** is an Android application designed to make unit conversions and everyday calculations simple and convenient.

The project combines a clean, intuitive interface with practical conversion and calculator functionality.

## Features

- Unit conversion
- Built-in calculator
- FROM and TO value selection
- Quick value swapping
- Conversion formula display
- Simple and intuitive interface
